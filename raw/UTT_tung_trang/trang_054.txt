Giải thích: 
Dòng lệnh 7: Vế trái là biến x, là biến đang cần đƣợc xác định giá 
trị. Vế phải là một biểu thức (a - b / 3 + c * 2 - 1). Tính giá trị của biểu 
thức dựa vào giá trị đã gán a = 9, b = 12, c = 3. Kết quả thu đƣợc, giá trị 
của biểu thức (a - b / 3 + c * 2 - 1) = 9 - 12/3 + 3*2 - 1 = 10.00. Nhƣ vậy, 
câu lệnh gán x = a - b / 3 + c * 2 - 1 cho kết quả x = 10.00. 
Dòng lệnh 8: Vế trái là biến y, cần tính giá trị. Vế phải là biểu thức 
(a - b / (3 + c) * (2 - 1)). Biểu thức bên vế phải đƣợc tính giá trị với a = 9, 
b = 12, c = 3. Kết quả thu đƣợc, giá trị của biểu thức = 7.00. Do đó kết 
quả in ra màn hình ở câu lệnh 11 là y = 7.00 
Tƣơng tự với dòng lệnh 9: Tính giá trị biểu thức (a - ( b / (3 + c) * 
2) - 1) với a = 9, b = 12, c = 3, kết quả của biểu thức = 4.00 đƣợc gán cho 
biến z và in ra màn hình ở dòng lệnh 12 là z = 4.00.
