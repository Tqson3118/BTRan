Trong chƣơng trình trên cấu trúc else if đƣợc lồng vào trong cấu trúc 
dạng 2 (từ dòng 7 đến 26), trong cấu trúc else if ta không cần đặt trong 
khối vì tất cả các if trong cấu trúc này đều có else, nên  câu lệnh sau else 
cuối cùng: printf("\nNhap diem khong hop le") thuộc về khối lệnh: if (dtb 
>= 0 && dtb <= 10).  
Giả sử trong cấu trúc else if không có dòng 25 (else printf("\nLoai 
gioi")) thì khi đó dòng 27 (else printf("Nhap diem khong hop le.\n")) đƣợc 
chƣơng trình hiểu nằm trong cấu trúc else if, mà không thuộc về câu lệnh if 
(dtb>=0 && dtb<= 10). Trong trƣờng hợp đó bạn cần phải đặt cấu trúc else

mới đƣợc hiểu là phần sau của câu lệnh if (dtb >= 0 && dtb <= 10).
