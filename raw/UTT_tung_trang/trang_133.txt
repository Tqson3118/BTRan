Viết chƣơng trình giải phƣơng trình bậc 2: ax2 + bx + c = 0. 
 Phác họa lời giải: 
Sử dụng biến delta để xác định biến của chƣơng trình:  
delta = b*b - 4 * a * c; 
Xét delta 
+ Nếu delta > 0 thì phƣơng trình có 2 nghiệm phân biệt: 
x1 = (-b + sqrt(delta))/(2*a) 
x2 = (-b - sqrt(delta))/(2*a) 
+ Nếu delta = 0 thì phƣơng trình có 1 nghiệm kép. 
x1 = x2 = -b/(2*a) 
+ Nếu delta < 0 thì phƣơng trình vô nghiệm.
