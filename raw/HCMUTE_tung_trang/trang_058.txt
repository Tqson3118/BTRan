2.3.2 Lệnh if đủ
Không giống với lệnh if thiếu, lệnh if đủ sẽ lựa chọn và quyết định 
thực hiện một trong hai khối lệnh cho trước tùy thuộc vào kết quả luận 
lý của biểu thức. 
 Cú pháp
if (biểu thức)
   {
     Khối lệnh 1;
    }
else
   {
     Khối lệnh 2;
   }
